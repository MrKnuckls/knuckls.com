# knuckls.com — LOGS Page for ELEMENTOR (basic, copy-paste per widget)

NOTE: "Logs" is a BLOG. In Elementor you have two options:
  A) Use a normal WordPress Posts page (recommended): create a Page called "Logs",
     set it as your Posts page in WordPress Settings > Reading. New entries = Posts.
  B) Or drop an "Archive Posts" / "Posts" Elementor widget on a blank page.

Below is the page header + a SAMPLE first post you can publish.

Server wipes, lab upgrades, patch notes, and the occasional "why is the power out" post. Newest first.
