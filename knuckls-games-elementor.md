# knuckls.com — Games Page for ELEMENTOR (basic, copy-paste per widget)

HOW TO USE:
- In Elementor, add a Section, then drag in the widget type shown.
- Paste the text below into that widget. That's it.
- Set section Background = #0d1117 (near-black). Text color = #e6edf3.
- Headings font = Rajdhani. Body font = Inter. (Set in widget Style tab, or theme.)
- Accent green #39d353 for heading text or underline. Amber #ffb000 for "alert" lines.
